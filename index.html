01 — About

Quality from the user's view and the system's.

I'm a QA Analyst focused on manual, regression, API, and end-to-end testing, with hands-on experience validating web applications and building automated test coverage using Playwright. I enjoy breaking down complex workflows, finding the edge cases, and making sure features work reliably from both the user and system perspectives.

I graduated Cum Laude in Information Technology, majoring in Information Security, from the University of Southeastern Philippines. That background shows up in how I test: detail-oriented and security-conscious. I'm most interested in test automation, system reliability, API validation, and improving QA processes.

During my internship I worked across development and QA. I wrote test documentation, validated system features, and ran both manual and automated tests. At Arrow, I investigated defects, validated backend and API behavior, and expanded automated coverage with Playwright.

I'm also growing into frontend development. I built the Vue frontend for my capstone, HookEdu, and I enjoy how the two sides feed each other: testing shows me where interfaces tend to break, and building them makes me a sharper tester.
